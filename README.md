# Zerodha Clone – Frontend

A frontend clone of the Zerodha website built using **React.js**.  
This project replicates the UI and basic navigation of Zerodha’s official website.

---

## 🚀 Features

- Responsive landing page
- Home, About, Pricing, Products, Signup, and Support pages
- Reusable components (Navbar, Footer, Hero sections)
- Clean folder structure
- Client-side routing
- Custom UI assets and images

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **React Router**

##  How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Mrudula-5/zerodha-clone-frontend.git

2.Navigate into the project:
cd zerodha-clone-frontend

3.Install dependencies:
npm install

4.Start the development server:
npm start

5.Open in browser:
http://localhost:3000
